## Risks

**No new risks — nothing changed in this window.** Standing risks documented in
the repository are carried forward unchanged:

- **Exactly-once boundary** — a job row is stored before the provider submit;
  interruption in between can orphan a paid provider generation (startup
  recovery mitigates, does not eliminate).
- **Single-instance polling** — in-process poller; no durable queue, horizontal
  scaling, or webhooks.
- **SSRF / media safety** — external media URLs are validated as `http(s)`
  only; allowlists and server-side ingestion remain an unimplemented extension
  point.
- **Mutable image tag** — deployment manifests still reference a `:latest`
