# Agent delivery contract

Read `docs/PRD.md` before changing code.

- Build the complete vertical slice; do not stop after scaffolding.
- Keep all MiniMax credentials server-side and never commit secrets.
- Use TypeScript strict mode and feature-first modules.
- Validate all external input and keep the MiniMax transport behind a small,
  independently testable interface.
- Run tests, type checks, linting, and production builds before finishing.
- Add exact local setup, mock-mode, and deployment instructions to the README.
- Do not push branches or create pull requests yourself. Cloud owns delivery.
